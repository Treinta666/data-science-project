# Palmer Penguins data

## Source

- Original dataset: https://github.com/allisonhorst/palmerpenguins
- CSV used by this analysis: `inst/extdata/penguins.csv` from the project above
- Retrieved: 2026-10-21

## Columns

| Column | Meaning |
|---|---|
| `species` | Penguin species: Adelie, Chinstrap, or Gentoo |
| `island` | Island where the observation was recorded |
| `bill_length_mm` | Culmen (bill) length in millimetres |
| `bill_depth_mm` | Culmen (bill) depth in millimetres |
| `flipper_length_mm` | Flipper length in millimetres |
| `body_mass_g` | Body mass in grams |
| `sex` | Recorded sex of the penguin |
| `year` | Observation year |
